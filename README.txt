# EL BLOQUE — Sitio web inicial

Archivos:
- index.html — página principal
- styles.css — diseño responsive
- script.js — menú móvil y año automático
- privacidad.html — página de privacidad
- terminos.html — términos
- contacto.html — contacto
- assets/personajes.jpg — póster de personajes generado para el proyecto

IMPORTANTE ANTES DE ADSEnSE:
1. Sustituye contacto@tudominio.com por un correo real.
2. Compra/conecta un dominio propio y publica el sitio.
3. Completa los capítulos con contenido original suficiente; no dejes una plantilla vacía.
4. Añade el código de AdSense únicamente cuando Google te lo proporcione y cuando el sitio esté listo.
5. Revisa las políticas de Google AdSense y los requisitos de consentimiento/cookies aplicables a tus visitantes.
6. Añade URLs reales para redes sociales y cualquier video oficial.

Este paquete NO contiene un ID de AdSense inventado. El código de AdSense debe generarse desde tu propia cuenta.
